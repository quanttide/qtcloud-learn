# 概览（dashboard）

LMS 管理后台的默认首页，聚合关键业务指标，作为管理员进入后台的第一屏。

## 页面定位

- **路由**: `/admin`（后台默认首页）
- **状态**: 统计卡片 + 待办概览，无子导航
- **数据依赖**: 各业务板块数据汇总（课题 / 双创项目 / 审批 / 成果）

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 统计卡片行 | `.stat-row` | flex 横向均分，`gap: 16px` |
| 统计卡片 | `.stat-card` | 大数字（30px 粗体）+ 标签（13px 灰色），hover 上浮 1px（详见 [widgets/items.md](../widgets/items.md) StatCard） |
| 待办列表 | `.todo-list` | 各板块待办摘要行，点击跳转对应板块页 |
| 快捷入口 | `.quick-links` | 卡片式入口，直接路由到板块页 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 点击统计卡片 | 点击任一 `.stat-card` | 跳转到对应板块列表页（待审批→审批中心） |
| 点击待办行 | 点击 `.todo-list` 行 | 跳转到对应板块页并定位到目标记录 |
| 点击快捷入口 | 点击 `.quick-links` 卡片 | 路由到对应板块页 |

## 数据模型

统计卡片数值来自各板块汇总（原型 Demo 数据）：待审批 5 / 执行中 12 / 已完成 8 / 已否决 3。生产环境由各板块 API 聚合。

## 设计原则

1. **一屏可扫** — 4 张统计卡 + 待办 + 快捷入口，无需滚动即可掌握全局
2. **数字可点击** — 每个指标都是入口，不设静态展示
3. **待办优先** — 待办中心列在统计卡下方，引导管理员处理未决事项

## 状态机

```
[后台框架] --> [概览]
                |-- 点击统计卡 / 待办 / 快捷入口 --> [对应板块页]
                +-- 刷新 --> 重新拉取聚合数据
```
