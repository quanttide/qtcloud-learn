# 咨询/工单（consult）

管理学员与外部咨询、工单记录，处理紧急程度与状态流转。

## 页面定位

- **路由**: `/admin/consult`
- **状态**: 数据表格列表，行内处理操作
- **数据依赖**: 工单 API（原型 Demo：3 条咨询记录）

## 页面结构

```
+-- 框架页 (admin.md) --------------------------------------------------+
|  +-- .section · 咨询/工单 -----------------------------------------+  |
|  |  .card > .datatable                                            |  |
|  |  +-- 表头：咨询人 | 问题类型 | 紧急程度 | 状态 | 时间 | 操作 -+  |  |
|  |  |  张同学   | 课程咨询 | 高   | 待处理 | 1h 前 | 处理 |     |  |
|  |  |  企业来访 | 合作咨询 | 中   | 处理中 | 1d 前 | 跟进 |     |  |
|  |  |  李同学   | 技术工单 | 低   | 已关闭 | 3d 前 | 查看 |     |  |
|  |  +------------------------------------------------------------+  |  |
|  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 数据表格 | `.datatable` | 咨询记录列表 |
| 紧急程度 | `.badge` | 高（红）/ 中（橙）/ 低（蓝），详见 [widgets/atoms.md](../widgets/atoms.md) |
| 行内操作 | `.btn.btn-filled.btn-sm` / `.btn-text.btn-sm` | 「处理 / 跟进 / 查看」 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 处理工单 | 点击「处理」 | 打开工单处理面板（回复 / 转派，待建设） |
| 跟进 | 点击「跟进」 | 更新工单状态 |
| 查看 | 点击「查看」 | 工单详情（对话记录） |

## 数据模型

```javascript
// ConsultTicket
{ id, from, type, urgency: 'high' | 'medium' | 'low',
  status: 'pending' | 'processing' | 'closed', createdAt }
```

## 设计原则

1. **紧急优先** — 紧急程度列常驻，可按紧急程度排序 / 筛选
2. **状态闭环** — 待处理 → 处理中 → 已关闭，操作即流转

## 状态机

```
[咨询/工单] --处理--> [处理面板] --回复/转派--> [处理中]
    +--跟进--> [状态更新]
    +--关闭--> [已关闭]
```
