# 验收评审表（review-form）

双创项目 Sale 阶段（第 5 阶段）的验收评审表单：三维评分 + 验收结论。

## 页面定位

- **路由**: 管理端 `/admin/forms/review`（模板管理）；审批人评审入口
- **状态**: 表单模板视图（管理端可编辑评分维度）
- **数据依赖**: 评审提交 API（原型为静态表单）

## 页面结构

```
+-- .form-page (全屏) ---------------------------------------------------+
|  +-- .form-header ------------------------------------------------+  |
|  |  ← 返回          验收评审表                      [保存模板]    |  |
|  +---------------------------------------------------------------+  |
|  +-- .form-body --------------------------------------------------+  |
|  |  +-- .form-left (60%) ----------------+  +-- .form-right (40%) + |  |
|  |  |  项目名称    [只读 · 展示]         |  |  评分标准说明        |  |
|  |  |  完成度      ★★★★☆ (4/5)          |  |  完成度：Demo 落地   |  |

|  |  |  验收结论    [下拉▾]               |  |                    |  |
```

## 组件清单

表单控件统一见 [widgets/forms.md](../widgets/forms.md)：

| 组件 | 说明 |
|------|------|
| 三维评分 | 星级评分（完成度 / 创新性 / 可复用性），5 分制 |
| 验收结论 | `select`：通过 / 有条件通过 / 不通过 |
| 评审意见 | `textarea`（可选） |
| 提交按钮 | `.btn.btn-filled`「提交评审」 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 提交评审 | 点击「提交评审」 | 校验三维评分 → 提交 → 项目状态流转（Sale 完成 / 打回） |
| 保存模板 | 管理端「保存模板」 | 评分维度结构持久化 |

## 数据模型

```javascript
// Review
{ projectId, scores: { completion, innovation, reusability }, // 1-5
  conclusion: 'pass' | 'conditional' | 'fail', comment, status }
```

## 设计原则

1. **同一套标准** — 三维评分固定口径，保证所有项目可比（呼应双创项目「同一套卷子」理念）
2. **结论可追溯** — 评分 + 结论 + 意见完整留存，归档到成果仓库

## 状态机

```
[双创项目 · 阶段 5] --> [验收评审]
                         |-- 通过 --> [项目结项 · 成果归档]
                         |-- 有条件通过 --> [补充修改 → 复审]
                         +-- 不通过 --> [打回阶段 4]
```
