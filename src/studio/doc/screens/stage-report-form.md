# 阶段报告模板（stage-report-form）

学员双创项目执行期的阶段报告表单模板，管理端维护模板结构，学员端按模板填报。

## 页面定位

- **路由**: 管理端 `/admin/forms/stage-report`（模板管理）；学员端按模板填报
- **状态**: 表单模板视图（管理端可编辑字段结构）
- **数据依赖**: 模板配置 + 报告提交 API（原型为静态表单）

## 页面结构

```
+-- .form-page (全屏) ---------------------------------------------------+
|  +-- .form-header ------------------------------------------------+  |
|  |  ← 返回          阶段报告模板                      [保存模板]    |  |
|  +---------------------------------------------------------------+  |
|  +-- .form-body --------------------------------------------------+  |
|  |  +-- .form-left (60%) ----------------+  +-- .form-right (40%) + |  |
|  |  |  报告阶段    [下拉▾]               |  |  模板说明            |  |
|  |  |  本周完成    textarea              |  |  每周提交一次        |  |
|  |  |  遇到的困难  textarea              |  |  导师将依据本报告    |  |
|  |  |  下周计划    textarea              |  |  评估进度与支持      |  |
|  |  |  需要帮助    [下拉▾]               |  |                    |  |
|  |  |  进度评估    [下拉▾]               |  |                    |  |
|  |  |  [提交报告]  [保存草稿]            |  |                    |  |
|  |  +-------------------------------------+  +--------------------+  |  |
|  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

## 组件清单

表单控件统一见 [widgets/forms.md](../widgets/forms.md)：

| 组件 | 说明 |
|------|------|
| 报告阶段 | `select`：阶段 1-5 或自定义 |
| 本周完成 | `textarea`（必填） |
| 遇到的困难 | `textarea` |
| 下周计划 | `textarea` |
| 需要帮助 | `select`：无 / 技术支持 / 资源支持 / 导师辅导 |
| 进度评估 | `select`：正常 / 滞后 / 超前 / 风险 |
| 提交按钮 | `.btn.btn-filled`「提交报告」 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 提交报告 | 点击「提交报告」 | 校验 → 提交 → 双创项目时间线追加节点 |
| 保存模板 | 管理端「保存模板」 | 模板字段结构持久化（管理端） |
| 保存草稿 | 点击「保存草稿」 | 预留 |

## 数据模型

```javascript
// StageReport
{ projectId, stage, done, blockers, nextPlan, helpNeeded, progress, status }
```

## 设计原则

1. **模板可配** — 管理端维护字段结构，学员端渲染同一模板，与立项申请表同构
2. **周报节奏** — 字段设计对齐一周执行粒度，帮助导师跟进

## 状态机

```
[学员端项目页] --> [阶段报告填报] --提交--> [报告归档 · 时间线+1]
[管理端表单配置] --> [模板编辑] --保存--> [模板更新]
```
