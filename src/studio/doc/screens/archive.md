# 成果仓库（archive）

存放学员双创项目的成果（Demo / 报告），支持查看、归档与状态标记。

## 页面定位

- **路由**: `/admin/archive`
- **状态**: 卡片网格展示成果条目
- **数据依赖**: 成果 API（原型 Demo：3 个项目卡片）

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 项目卡片 | `.archive-card` | flex:1 `min-width: 200px`，浅灰背景，图标 + 标题 + 作者时间 + 状态标签 |
| 状态 Badge | `.badge` | 已完成（浅紫）/ 执行中（浅绿）/ 待审批（浅蓝），详见 [widgets/atoms.md](../widgets/atoms.md) |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 打开成果 | 点击卡片 | 查看成果详情（Demo 展示 / 报告预览） |
| 归档 | 卡片操作菜单 | 标记归档（待建设） |

## 数据模型

```javascript
// ArchiveItem
{ id, title, icon, author, updatedAt, status: 'pending' | 'active' | 'done' }
```

## 设计原则

1. **成果即卡片** — 一卡一成果，标题 + 作者 + 状态一眼可见
2. **状态即流程** — Badge 与双创项目阶段联动，成果状态自动流转

## 状态机

```
[成果仓库] --打开--> [成果详情]
    +--归档--> [标记归档]
```
