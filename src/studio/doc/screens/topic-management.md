# 课题管理（topic-management）

管理学员课题（双创项目的前置立项单元），查看课题列表、状态与审批操作。

## 页面定位

- **路由**: `/admin/topics`
- **状态**: 数据表格列表，行内操作（审批 / 详情 / 驳回）
- **数据依赖**: 课题资源 API（原型 Demo：4 行课题数据）

## 页面结构

```
+-- 框架页 (admin.md) --------------------------------------------------+
|  +-- .section · 课题管理 ------------------------------------------+  |
|  |  .card > .datatable                                            |  |
|  |  +-- 表头：课题名称 | 团队 | 方向 | 状态 | 更新时间 | 操作 --+  |  |
|  |  |  AI 内容流水线      | 小亦   | 内容 | 待审批 | 2h 前  | 审批 |  |  |
|  |  |  数据看板           | 小橘子 | 数据 | 执行中 | 1d 前  | 详情 |  |  |

|  |  |  左移标准           | ...    | 方法 | 待审批 | 4d 前  | 审批 |  |  |
|  |  +------------------------------------------------------------+  |  |
|  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 数据表格 | `.datatable` | 全宽表格，13px 字号，表头灰底 2px 底线，行 hover 浅蓝背景（容器 `.card` 含表格时 `padding: 0`） |
| 状态 Badge | `.badge` | 待审批（浅蓝）/ 执行中（浅绿）/ 已完成（浅紫）/ 已否决（红），详见 [widgets/atoms.md](../widgets/atoms.md) |
| 行内操作 | `.btn.btn-filled.btn-sm` | 「审批」主操作 |
| 行内辅助 | `.btn.btn-text.btn-sm` | 「详情 / 查看 / 驳回」文字操作 |
| 状态筛选 | `.filter-bar` | 按状态 / 方向筛选（待建设） |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 审批课题 | 点击行内「审批」 | 跳转审批中心，预填该课题审批上下文 |
| 查看详情 | 点击「详情 / 查看」 | 打开课题详情（跳转双创项目管理页对应记录） |
| 驳回 | 点击「驳回」 | 二次确认后状态置为已否决 |
| 筛选 | 筛选栏（待建设） | 按状态过滤表格 |

## 数据模型

```javascript
// Topic（课题）
{ id, name, team, direction, status: 'pending' | 'active' | 'done' | 'rejected',
  updatedAt }
```

## 设计原则

1. **操作就近** — 审批按钮直接嵌在行内，不跳详情页操作
2. **状态可见** — Badge 常驻，状态流转即时刷新

## 状态机

```
[课题列表] --审批--> [审批中心 · 预填]
    |--驳回--> [确认] --> [已否决]
    +--详情--> [双创项目页 · 定位记录]
```
