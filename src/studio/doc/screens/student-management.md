# 学员管理（student-management）

查看学员信息、学习进度与活跃状态。学员账户 / 权益能力由 qtcloud-learn 学员侧承接，本页为管理视角。

## 页面定位

- **路由**: `/admin/students`
- **状态**: 数据表格列表，可按状态 / 进度筛选
- **数据依赖**: 学员 API（原型 Demo：5 名学员）

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 数据表格 | `.datatable` | 学员列表，行 hover 浅蓝背景 |
| 进度条 | `.progress-bar` | 单元格内迷你进度条（详见 [widgets/feedback.md](../widgets/feedback.md)） |
| 状态 Badge | `.badge` | 学习正常（浅绿）/ 已结课（浅紫）/ 停滞（浅橙） |
| 筛选栏 | `.filter-bar` | 状态下拉 + 进度下拉 |
| 行内操作 | `.btn.btn-text.btn-sm` | 「查看」进入学员详情 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 查看学员 | 点击「查看」 | 学员详情（进度明细 / 考核记录，数据来自学员侧服务） |
| 筛选 | 筛选栏 | 按状态 / 进度过滤列表 |
| 联系学员 | 行内操作（待建设） | 咨询/工单入口预填学员上下文 |

## 数据模型

```javascript
// Student
{ id, name, plan: 'free' | 'paid' | 'vip', courses: [{ id, progress }],
  lastActiveAt, status }
```

字段对齐 qtcloud-learn 统一领域模型（Student 含付费 / VIP 权益，见 [lms-inventory.md](../../../lms-inventory.md)）。

## 设计原则

1. **进度可视** — 进度条直接嵌入表格，一屏扫描全部学员学习状态
2. **管理视角** — 只读为主，操作（权限 / 权益调整）在学员详情中完成

## 状态机

```
[学员列表] --筛选--> [过滤结果]
    +--查看--> [学员详情 · 进度/考核]
```
