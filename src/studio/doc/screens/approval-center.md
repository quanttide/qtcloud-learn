# 审批中心（approval-center）

集中处理课题 / 项目审批：左侧时间线展示审批流转，右侧表单执行审批动作。

## 页面定位

- **路由**: `/admin/approvals`
- **状态**: 双栏布局（时间线 + 审批表单），可预填（从课题管理跳转）
- **数据依赖**: 审批记录 API（原型 Demo：4 节点时间线）

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 提交审批 | 点击「提交审批」 | 表单校验 → 提交 → 时间线追加节点 → toast 确认 |
| 驳回 | 点击「驳回」 | 二次确认后提交，时间线追加否决节点 |
| 预填进入 | 从课题管理「审批」进入 | 表单预填课题信息，时间线聚焦该课题 |

## 数据模型

```javascript
// Approval
{ id, topicId, timeline: [{ time, event }], conclusion: 'pass' | 'reject',
  comment, status }
```

## 设计原则

1. **流转可视化** — 时间线完整呈现审批生命周期，前后文一目了然
2. **操作就近** — 表单与时间线同屏，审批动作不离开上下文

## 状态机

```
[审批列表] --> [审批中心]
                |-- 提交 --> [时间线 +1 节点 · 状态流转]
                |-- 驳回 --> [确认弹窗] --> [已否决]
                +-- 预填进入 --> [表单预填 · 聚焦时间线]
```
