# 双创项目管理（innovation-project）

管理学员创新创业项目的五阶段流程：发现盲区 → 提交立项 → 总部审批 → 2 周执行 → Sale 给总部。

## 页面定位

- **路由**: `/admin/projects`
- **状态**: 流程条（Pipeline）+ 项目列表，可按阶段筛选
- **数据依赖**: 双创项目 API（原型 Demo：五阶段流程说明 + 静态数据）

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 流程条 | `.pipeline` | flex 横向均分，阶段节点间 `::after` 渲染 `→`（详见 [widgets/navigation.md](../widgets/navigation.md) Pipeline） |
| 阶段节点 | `.pipeline .stage` | `.icon`（44px 圆）+ `.name`（13px 粗体）+ `.hint`（11px 灰色） |
| 项目表格 | `.datatable` | 项目列表，行内操作按钮 |

### 五阶段

| 顺序 | 图标 | 名称 | 说明 |
|------|------|------|------|
| 1 | 💡 | 发现盲区 | 学员基于课程上下文找到公司可能感兴趣但还没做的方向 |
| 2 | 📝 | 提交立项 | 填写立项申请表，说清楚发现了什么、打算怎么做 |
| 3 | 🔍 | 总部审批 | 评估方向匹配度，分配资源支持等级 |
| 4 | 🚀 | 2 周执行 | 自由组队或个人，做出最小可行 demo |
| 5 | 🎤 | Sale 给总部 | 向管理层展示成果，同一套标准打分 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 查看阶段详情 | 点击 `.pipeline .stage` | 项目列表按该阶段筛选 |
| 打开项目 | 表格行「操作」 | 跳转课题管理/成果仓库对应记录 |
| 新建项目 | 顶部「＋ 新建」（待建设） | 进入立项申请表 |

## 数据模型

```javascript
// InnovationProject
{ id, name, team, stage: 1-5, resourceLevel: 'A' | 'B' | 'C', updatedAt }
```

## 设计原则

1. **流程即导航** — 五阶段流程条既是说明也是筛选入口
2. **标准统一** — Sale 打分使用同一套标准，管理端展示评分口径

## 状态机

```
[双创项目管理] --点击阶段--> [按阶段筛选列表]
    |--打开项目--> [课题管理 / 成果仓库 · 定位]
    +--新建--> [立项申请表]
```
