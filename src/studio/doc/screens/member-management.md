# 成员管理（member-management）

管理讲师 / 导师等团队成员：角色、状态与联系方式。

## 页面定位

- **路由**: `/admin/members`
- **状态**: 数据表格列表，行内操作
- **数据依赖**: 成员 API（原型 Demo：4 人：李明 / 王芳 / 陈强 / 赵子奕）

## 页面结构

```
+-- 框架页 (admin.md) --------------------------------------------------+
|  +-- .section · 成员管理 ------------------------------------------+  |
|  |  .card > .datatable                                            |  |
|  |  +-- 表头：姓名 | 角色 | 状态 | 联系方式 | 操作 ------------+  |  |
|  |  |  李明   | 导师   | 在职   | ...      | 编辑  |            |  |  |
|  |  |  王芳   | 讲师   | 在职   | ...      | 编辑  |            |  |  |
|  |  |  陈强   | 讲师   | 休假   | ...      | 编辑  |            |  |  |
|  |  |  赵子奕 | 助教   | 在职   | ...      | 编辑  |            |  |  |
|  |  +------------------------------------------------------------+  |  |
|  |  [+ 添加成员]                                                  |  |  |
|  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 数据表格 | `.datatable` | 全宽表格，行 hover 浅蓝背景 |
| 行内操作 | `.btn.btn-text.btn-sm` | 「编辑」文字操作 |
| 添加按钮 | `.btn.btn-outlined` | 「＋ 添加成员」，打开成员表单 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 编辑成员 | 点击「编辑」 | 行内展开表单或弹窗（待建设） |
| 添加成员 | 点击「＋ 添加成员」 | 新建成员表单 |

## 数据模型

```javascript
// Member
{ id, name, role: 'mentor' | 'teacher' | 'assistant', status: 'active' | 'leave',
  contact }
```

## 设计原则

1. **轻量管理** — 成员字段少，编辑就地完成，不设详情页
2. **状态常驻** — 在职 / 休假状态列显示，不折叠进菜单

## 状态机

```
[成员列表] --编辑--> [就地编辑行] --保存--> [刷新]
    +--添加--> [新建表单] --提交--> [新行]
```
