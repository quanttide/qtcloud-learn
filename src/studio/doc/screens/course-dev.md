# 课程研发（course-dev）

关联系统板块：展示课程研发相关内容（内容"左移"标准、知识工程教程等）。课程制作能力归 qtcloud-course，本页为研发资讯视图。

## 页面定位

- **路由**: `/admin/course-dev`
- **状态**: 卡片网格，只读展示
- **数据依赖**: 静态内容（原型 Demo：2 张卡片）

## 页面结构

```
+-- 框架页 (admin.md) --------------------------------------------------+
|  +-- .section · 课程研发 ------------------------------------------+  |
|  |  .card-grid（flex）                                            |  |
|  |  +--------------------------------+ +------------------------+  |  |
|  |  | 📐 内容"左移"标准              | | 📚 知识工程教程         |  |  |
|  |  | 把制作前置到内容生产阶段        | | 从零到一搭建知识库      |  |  |
|  |  | [查看]                         | | [查看]                  |  |  |
|  |  +--------------------------------+ +------------------------+  |  |
|  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 卡片 | `.card` | 双栏卡片（flex），图标 + 标题 + 描述 + 操作（详见 [widgets/containers.md](../widgets/containers.md)） |
| 查看按钮 | `.btn.btn-text` | 打开研发内容详情 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 查看内容 | 点击「查看」 | 打开研发内容详情（外部文档或跳转 qtcloud-course） |

## 数据模型

```javascript
// CourseDevItem
{ id, title, description, link }
```

## 设计原则

1. **单向链接** — 本页只做入口聚合，内容能力沉淀在 qtcloud-course，避免管理后台重复造轮子

## 状态机

```
[课程研发] --查看--> [研发内容详情 / qtcloud-course]
```
