# 课程管理（course-management）

后台维护课程配置信息（名称 / 班级 / 状态等），提供新建课程入口。课程内容制作归 qtcloud-course，本页只做 LMS 侧课程配置。

## 页面定位

- **路由**: `/admin/courses`
- **状态**: 数据表格列表 + 新建入口
- **数据依赖**: 课程配置 API（原型 Demo：5 门课程配置信息）

## 组件清单

| 组件 | 选择器/ID | 说明 |
|------|-----------|------|
| 数据表格 | `.datatable` | 课程配置行，行 hover 浅蓝背景 |
| 状态 Badge | `.badge` | 已发布（绿）/ 草稿（橙），详见 [widgets/atoms.md](../widgets/atoms.md) |
| 配置按钮 | `.btn.btn-text.btn-sm` | 「配置」进入课程设置 |
| 新建按钮 | `.btn.btn-outlined` | 「＋ 新建课程」 |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 配置课程 | 点击「配置」 | 打开课程配置（班级绑定 / 上架状态，内容编辑跳 qtcloud-course） |
| 新建课程 | 点击「＋ 新建课程」 | 新建课程配置行（内容制作引导至 qtcloud-course Studio） |

## 数据模型

```javascript
// CourseConfig
{ id, name, type: 'theory' | 'practice', target, status: 'draft' | 'published',
  progress }
```

## 设计原则

1. **职责分离** — 本页只管 LMS 侧配置（班级 / 状态），课程内容制作明确引导至 qtcloud-course，避免后台膨胀
2. **课程阶梯可见** — 与前台课程阶梯（原型 5 门课）一一对应，配置状态同步前台展示

## 状态机

```
[课程管理] --配置--> [课程设置]
    |--新建--> [新建配置] --提交--> [新行 · 草稿]
    +--发布/下架--> [status 切换] --> [前台课程列表同步]
```
