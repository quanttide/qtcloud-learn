# 立项申请表（apply-form）

学员双创项目立项申请表单，双创项目五阶段流程的第 2 阶段（提交立项）。学员端填写，管理端预览 / 审核。

## 页面定位

- **路由**: 学员端 `/apply`；管理端 `/admin/forms/apply`（模板管理）
- **状态**: 全屏表单页（原型 `#form-page`），可独立打开
- **数据依赖**: 表单提交 API（原型为 Demo，无实际提交逻辑）

## 组件清单

表单控件统一见 [widgets/forms.md](../widgets/forms.md)：

| 组件 | 说明 |
|------|------|
| 项目名称 | `input[type=text]`（必填） |
| 盲区描述 | `textarea`（必填，说明发现了什么、为什么值得做） |
| Demo 方案 | `textarea`（必填，打算怎么做） |
| 方向类型 | `select`：内容 / 数据 / 渠道 / 方法 等 |
| 组队方式 | `select`：个人 / 自由组队 / 指定组队 |
| 提交按钮 | `.btn.btn-filled`「✓ 提交申报」 |
| 草稿按钮 | 「保存草稿」（预留，当前无持久化） |
| 布局 | `.form-left`（60%）+ `.form-right`（40% 装饰圆 / 提示区） |

## 交互与导航

| 交互 | 触发条件 | 行为 |
|------|---------|------|
| 提交申报 | 点击「✓ 提交申报」 | 校验必填 → 提交 → 进入双创项目第 3 阶段（总部审批） |
| 保存草稿 | 点击「保存草稿」 | 预留（当前无实际持久化） |
| 返回 | 表单头「← 返回」 | 返回来源页（学员端课程页 / 管理端双创项目页） |

## 数据模型

```javascript
// Application
{ projectName, blindSpot, demoPlan, direction, teamMode, status: 'draft' | 'submitted' }
```

提交后生成课题记录（topic-management）并进入审批流（approval-center）。

## 设计原则

1. **一屏完成** — 全屏表单，字段一次填完，不滚动分步
2. **示例引导** — 右侧提示区展示填写示例，降低立项门槛
3. **双端共用** — 学员端填写、管理端预览同一表单结构（管理端为模板视图）

## 状态机

```
[入口] --> [立项申请表]
            |-- 提交 --> [双创项目 · 阶段 3 审批]
            +-- 保存草稿 --> [草稿状态]（待建设）
```
