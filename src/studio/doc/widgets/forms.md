# Forms — 表单组件

---

## 1. FormGroup (.form-group)
字段组：`margin-bottom:16px`。`label`（13px 粗体）+ 输入控件。`:focus` 边框变蓝。

## 2. Input (input[type=text])
文本输入：`width:100%`，`padding:10px 14px`，1.5px 浅灰边框，圆角 8px，`:focus` 蓝边框。

## 3. Textarea (textarea)
多行文本：`min-height:90px`，`resize:vertical`，其余同 Input。

## 4. Select (select)
下拉选择：同 Input 样式。选项涵盖：方向类型、组队方式、资源等级、报告阶段、帮助需求、进度评估、验收结论、评分、问题类型、紧急程度。

## 5. Radio (input[type=radio])
单选：`accent-color:var(--brand)`。用于立项申请表预览页。
